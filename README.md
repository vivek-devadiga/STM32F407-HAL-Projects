# STM32F407 HAL Projects

Collection of STM32F407 embedded projects developed using STM32CubeMX, STM32CubeIDE, and STM32 HAL drivers.

## Projects

### LED_IR
- IR sensor interfacing with STM32F407
- LED control based on IR sensor detection
- Developed using STM32 HAL

## Hardware
- STM32F407VG
- IR Sensor Module
- LED

## Software
- STM32CubeMX
- STM32CubeIDE
- STM32 HAL Drivers
